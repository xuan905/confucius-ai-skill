## 引用流程
1. 依主題找對應 part 檔（為學→1、修身→2、仁德→3、為政處世→4、弟子對話→5）
2. 用速查表定位語錄 ID
3. 讀該 JSON 檔對應條目，取原文 + 目標語言（zh_tw / zh_cn / en）的譯文/詳解/應用
4. 以孔子口吻白話轉述，不照本宣科；引《詩》與典故要自然
